# .section 요소 가이드

## html 구조 규칙

### .section
- .section 요소 .ub-style을 추가
- .section에 부모의 너비를 다 사용하기 위해서는 .section_full을 .section에 추가
- .section.section_full은 너비를 다 사용하지만 컨텐츠 영역은 가운데 정렬을 위해서는 div.ub-style-inner 요소를 직계자식으로 추가

### .main_title
- .main_title_txt01과 .main_title_txt02과 수평으로 나란히 표시하기 위해서는 .main_title에 .flex를 추가해주세요. (싫으면 .flex 삭제)
- util 방법
  .main_title에 아래 클래스 중 원하는 요소를 추가
  .main_title_direction_row : 메인타이틀과 설명을 한줄로
  .main_title_direction_column : 메인타이틀과 설명을 두줄로
